# 文体ルール（全テンプレート共通）— 禁止表現リストと言い換えルール

台本・ネタ一覧の文章はすべてこのルールに従う。人間の教養系ナレーターの原稿のように書く。
事実を具体的に、言い切りで、短い文で。1文は40〜60字程度が目安。

## 1. 禁止表現（読み上げ文・見出し・要点・概要欄のどこにも出さない）
| 禁止 | 言い換えの方針 | 例 |
|---|---|---|
| 静かに / そっと | 削る。動作そのものを書く | 「静かに長生きしている」→「長持ちします」 |
| ゆっくり / ゆっくりと | 削る。睡眠回の挨拶も普通の言葉にする | 「ゆっくりおやすみなさい」→「おやすみなさい」 |
| 心地よい | 削る | — |
| 〜ではないでしょうか / 〜と言えるでしょう / といえるでしょう | 言い切る | 「仕組みだと言えるでしょう」→「仕組みです」 |
| いかがでしたか | 内容のまとめか次回予告にする | 「いかがでしたか」→「今日は〜を10個お話ししました」 |
| 奥深い / 興味深い | 何がどう面白いのか、事実で書く | 「奥深い歴史」→「400年続いた制度」 |
| 実は〜なのです（の多用） | 「実は」を削り、意外な事実をそのまま書く。俗説の否定は「ところが、〜の研究では」 | 「実は、法律に答えがあります」→「答えは法律にあります」 |
| まさに / つまり / ここで / さあ | 削る。前後の文をつなぎ直す | 「つまり、高額なお札ほど」→「高額のお札ほど」 |
| 〜の世界へ / 旅 / 紐解く / ひもとく | 削る。扱う内容を名詞で言う | 「お金の歴史を紐解く旅へ」→「今日のテーマは、お金の歴史です」 |
| 秘密 / ひみつ / 鍵 | 具体的な名詞にする | 「お札の紙のひみつ」→「お札の紙の原料」 |
| 〜してみてください | 事実の提示か、必要なら「〜できます」 | 「傾けてみてください」→「傾けると、肖像が回って見えます」 |
| 〜かもしれませんね | 根拠があれば言い切る。なければ「〜とされます」「〜という説があります」 | — |
| 重要なのは〜 / ポイントは〜 / 大切なのは〜 | 削り、その中身を主語にして書く | 「ポイントは会費です」→「利益の柱は会費です」 |
| 過剰な感嘆（！、驚きですね、すごいですね） | 使わない | — |
| 情緒的な比喩（〜が眠っている、〜が宿る、心をほどく 等） | 事実に置き換える | 「谷の風景が眠っている」→ 削除 |

## 2. 文末と構成のルール
- 同じ文末を3回続けない。特に「〜のです」「〜のですね」「〜ですね」「〜でしょうか」を連続させない。
- 文末は「〜です／〜ました／〜でした／〜とされます／〜と定めています」などを混ぜる。体言止めも使ってよい（例:「制度が始まったのは2008年。」）。
- 「〜のですね」「〜ですね」は原則使わない。
- 三つ並べの列挙（「AもBもCも」「〜し、〜し、〜する」）を決まり文句として使わない。事実として三つある場合（例: 金貨・銀貨・銭）は可。
- hook は問いかけにするが、毎回「〜のでしょうか」にしない。「〜か。」「〜をご存じですか。」などで変化をつける。
- rich_point は「お金持ち視点では、〜」で始めてよいが、締めは毎回変える。教訓めいた決まり文句（「〜が大切なのですね」）で終えない。
- 睡眠用は、文を短くし、声のトーンで静かさを出す。文章で「静か」「穏やか」と説明しない。冒頭の挨拶は2〜4文、締めは「おやすみなさい。」で終える。

## 3. 提出前の機械チェック
次のコマンドで0件になることを確認する（対象は台本JSONとネタJSON）。
```
grep -nE '静か|そっと|ではないでしょうか|いかがでしたか|と言えるでしょう|といえるでしょう|奥深|興味深|まさに|つまり|ここで|さあ|ゆっくり|心地よ|の世界へ|旅|紐解|ひもと|秘密|ひみつ|鍵|してみてください|かもしれませんね|重要なのは|ポイントは|大切なのは|のですね|実は' content/scripts/*.json content/topics.json
```
※「旅」は「旅客機」「旅行」などにも当たるので、当たった場合は語を変える（例: 旅客機→超音速機）。
