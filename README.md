# マインドマップ

ブラウザで使えるマインドマップ（XMind 風）。サーバー不要の静的サイトで、GitHub Pages で公開できます。

## できること

- 中心トピックから右方向へ枝を自動配置
- トピックの追加・編集・削除、ドラッグでの付け替え、折りたたみ
- `⌘B` / `Ctrl+B` で太字（編集中は選んだ文字だけ、選択中はトピック全体）
- 元に戻す / やり直し、ズーム・画面移動（トラックパッド・ピンチ対応）
- 共有URL（閲覧専用）の発行
- PNG 画像・JSON（バックアップ）の書き出し、JSON の読み込み

## 保存と共有のしくみ

- 編集中のマップはブラウザの `localStorage` に自動保存されます（他の端末とは同期されません）。
- 「共有」を押すと、マップを圧縮して URL の `#` 以降に埋め込んだ閲覧専用 URL を作ります。
  データは URL 自体に入っているので、サイトが公開されている限りずっと開けます。
- 共有 URL はその時点の内容です。マップを直したら URL を発行し直してください。

## ショートカット

| キー | 動作 |
| --- | --- |
| Tab | 子トピックを追加 |
| Enter | 同じ階層に追加（編集中は確定） |
| ダブルクリック / Space / F2 | 文字を編集 |
| Shift + Enter（編集中） | 改行 |
| ⌘/Ctrl + B | 太字 |
| Delete / Backspace | 削除 |
| 矢印キー | 選択を移動 |
| ⌘/Ctrl + / | 折りたたみ / 展開 |
| ⌘/Ctrl + Z / Shift + Z | 元に戻す / やり直し |
| ⌘/Ctrl + ホイール、ピンチ | 拡大・縮小 |

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. デフォルトブランチに push すると `.github/workflows/pages.yml` が自動で公開する

## ローカルで動かす

ES モジュールを使うので、ファイルを直接開くのではなく簡単なサーバー経由で開きます。

```sh
npx serve .
```

## ファイル構成

- `index.html` … 入口
- `assets/app.js` … 画面（一覧・編集・閲覧）とツールバー
- `assets/mindmap.js` … マップ本体（配置・描画・編集・ドラッグ・ズーム）
- `assets/model.js` … データ構造、太字だけを許す本文の整形、配色
- `assets/share.js` … 共有 URL の圧縮・復元
- `assets/storage.js` … ブラウザへの保存
- `assets/export.js` … PNG / JSON 書き出し
